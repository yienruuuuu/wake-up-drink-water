# Windows 健康提醒工具規格草案

狀態：第一版已實作；視窗互動與登入／休眠行為仍需 Windows 實機驗收。

## 已確認需求

- 僅支援 Windows。
- 提供喝水、起來走走、眨眼提醒。
- 可在背景運行，支援開機自動啟動。
- 資源占用必須非常低，為主要設計限制。
- 提醒出現後，必須保留到使用者明確確認才消失。

## 第一版範圍

- 系統匣常駐，平時不開啟主視窗。
- 三種提醒可獨立啟用、停用及設定間隔。
- 使用持續顯示的非模態提醒視窗，提供「我知道了」按鈕。
- 提醒出現時顯示在其他視窗上方，但不主動搶走鍵盤焦點；不阻止使用者操作其他程式。
- 提醒視窗不提供關閉按鈕；Escape 不關閉，Alt+F4 不視為確認。使用者仍可從系統匣退出整個程式。
- 多項提醒到期時合併在同一個視窗，各項可獨立確認。
- 同一項提醒未確認時不重複新增；確認後，才開始計算該項的下一個間隔。
- 提供全域暫停與恢復功能；暫停不自動確認或隱藏已出現的提醒。
- 設定僅儲存在本機，重啟後保留。不需要帳號、連網或雲端同步。
- 第一版不做健康統計、完成紀錄或自動偵測使用者是否真的喝水、走動、眨眼。

## 行為與驗收條件

### Scenario：到期提醒持續等待確認

Given 某項提醒已啟用，且目前沒有暫停
When 該項提醒間隔到期
Then 顯示該項提醒
And 在使用者明確確認前不自動消失

Acceptance Criteria:
- 經過時間、點擊其他程式、Escape 或 Alt+F4 都不將提醒標記為已確認。
- 按下該項確認按鈕才移除該項提醒。
- 所有項目確認後，提醒視窗關閉。
- 關閉設定畫面不會退出背景程式。

Test Notes:
- 驗證提醒狀態轉換，並手動驗證焦點與視窗行為。

### Scenario：未確認期間不堆積重複提醒

Given 喝水提醒正在等待確認
When 又經過一個喝水提醒間隔，或其他提醒到期
Then 喝水提醒仍只有一筆
And 其他到期提醒加入同一視窗

Acceptance Criteria:
- 每種提醒最多只有一筆待確認項目。
- 確認某項後，以確認時間為起點安排該項下次提醒。
- 確認某項不會確認其他項目，也不會重設其他項目的時間。

Test Notes:
- 使用可控制的時鐘驗證去重與各項獨立計時。

### Scenario：暫停後恢復提醒

Given 使用者已暫停提醒
When 暫停期間有提醒到期
Then 不新增提醒
And 已經顯示的提醒仍保留到確認

Acceptance Criteria:
- 支援手動恢復；限時暫停的選項另行確認。
- 恢復時，各項沒有待確認提醒的計時器重新開始。
- 不補發暫停期間累積的提醒。

Test Notes:
- 驗證暫停、確認與恢復交錯發生時的狀態。

### Scenario：休眠或鎖定後恢復使用

Given 電腦進入睡眠或 Windows 鎖定
When 電腦喚醒且使用者解鎖
Then 不連續補發離開期間的提醒
And 各項沒有待確認提醒的計時器重新開始

Acceptance Criteria:
- 鎖定期間不新增提醒視窗。
- 離開前已待確認的項目於解鎖後仍保留。
- 程式退出後不保留待確認項目；下次啟動重新計時。

Test Notes:
- 驗證睡眠、喚醒、鎖定、解鎖事件及待確認項目的保留。

### Scenario：背景啟動與設定保留

Given 使用者已儲存設定並啟用開機啟動
When 使用者重新登入 Windows
Then 程式在系統匣啟動並套用已儲存設定
And 不自動打開設定畫面

Acceptance Criteria:
- 使用者可開啟或關閉登入時自動啟動。
- 同一使用者重複啟動程式時，不產生多組計時器或重複提醒。
- 無效的提醒間隔不能儲存；允許範圍待確認。

Test Notes:
- 手動驗證登入啟動與設定持久化；驗證單一執行個體。

## 技術方向與資源驗證

- 使用 Rust + Win32 API，透過 windows-sys 呼叫系統 API，不依賴 .NET。
- 目前建置目標為 Windows 10 / 11 x64；C 執行階段靜態連結。
- 使用事件與計時器，不以高頻輪詢等待提醒。
- 不引入瀏覽器執行環境或本機 HTTP 伺服器。
- 原型需量測：閒置 CPU、常駐記憶體、背景喚醒頻率、啟動時間與發行大小。
- 量測需記錄 Windows 版本、建置模式、硬體、觀察時長，以及提醒視窗是否開啟。
- 尚未訂定資源數值門檻，不宣稱已達到低資源目標。

## 待確認決策

1. 透過實機量測確認資源門檻。
2. 是否需要會議／全螢幕偵測，以及限時暫停；第一版不偵測，採手動暫停。

## 第一版預設與補充行為

- 喝水 30 分鐘、走動 60 分鐘、眨眼 20 分鐘，全部啟用；允許 1–1440 分鐘。
- 無提示音；自啟動預設關閉，需使用者在設定中開啟。
- 置頂、不搶焦點並允許繼續操作其他程式的提醒方式已由使用者確認。
- 設定畫面提供「預覽提醒」，將已啟用項目加入實際待確認提醒；確認後依正常間隔重新計時。
- 停用某項提醒會撤銷該項待確認提醒；修改間隔不撤銷待確認項目。
- 已暫停或鎖定時修改設定，不會開始派發提醒。
- 設定損毀時明確報錯並停止啟動，不靜默覆寫原檔。
